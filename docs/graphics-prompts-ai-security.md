# AI and cybersecurity illustration prompts

These are conceptual domain illustrations for the Johnaverse portfolio. They are not deployment evidence, operational topology diagrams, or screenshots of real systems.

- Generation mode: built-in `image_gen.imagegen`, one brand-new generation call per domain.
- Reference images: none. No previous images were included.
- Transparent background: false.
- Web processing: format conversion and proportional resizing only, using Pillow LANCZOS and WebP quality 86. No compositing, recoloring, cropping, or visual editing through scripts.
- Main image width cap: 1600 px. Both generated images were 1536 × 1024, so the main variants retain their original dimensions.
- Output directory: `public/images/domains/`.
- Original generated PNGs remain in the built-in generated-images directory.
- Visual QA: inspected each original and its 640 px WebP variant. AI contains the core, four peripheral modules, and a control gate. Cybersecurity contains a shield, inspection lens, and three service modules. Both retain legibility at the small size, with no text, logos, people, or screenshots.

## AI exact prompt

```text
Use case: stylized-concept
Asset type: AI & Automation domain illustration for a professional infrastructure engineering portfolio.
Primary request: create one striking but restrained editorial 3D illustration of a luminous violet/lilac model core orchestrating exactly four smaller agent modules through a visible abstract control gate.
Scene/backdrop: seamless deep charcoal studio background matching #101719, a shallow matte charcoal platform, no room or scenery.
Subjects: a substantial central frosted-glass and graphite cuboid model core with subtle lilac light held inside it; four separated compact tactile agent modules arranged around it, two on either side at different depths; thin precise violet connections arranged in an orderly workflow; a single architectural control-gate frame between the core and two forward modules, suggesting a deliberate boundary without implying a real deployed topology. Modules are abstract hardware-like geometric forms with no brands, no screens, and no text.
Style/medium: refined premium editorial 3D product illustration, slightly isometric three-quarter perspective, crisp industrial geometry, matte graphite, brushed metal edges, translucent glass, soft physically plausible contact shadows.
Composition/framing: wide landscape about 3:2. The primary objects fill roughly 75 percent of the frame, generous clear perimeter margins, all modules and the gate fully visible, composition centered and legible at thumbnail size. Layered depth with careful separation.
Lighting/mood: soft neutral key light, bright readable edges, selective lilac/violet emission in the core and connections, restrained glow, calm technical confidence.
Color palette: charcoal and graphite with silver-gray surfaces and violet/lilac accents; no blue/cyan or green accents.
Constraints: conceptual illustration only, not a diagram documenting actual operational topology. Exactly four peripheral agent modules. No people, faces, brains, robots, mascots, text, labels, logos, numbers, watermark, fake screenshots, real configuration, code, monitoring charts, rack scenery, cables, or decorative clutter. Do not put labels into the image. Opaque background.
```

# Cloud and Blockchain domain illustrations

Mode: built-in `image_gen` generation, with no reference images and an opaque background. Use case: `stylized-concept`.

These are conceptual editorial illustrations, not photographs, technical diagrams, or evidence of any actual deployment.

## Output and processing

Both generated PNG sources were 1536 × 1024 pixels (3:2). The selected images were converted to RGB WebP with Pillow, quality 86, encoder method 6. Responsive variants use Lanczos resizing with no crop or upscaling. Original-width assets remain below the requested 1600-pixel cap.

## Exact Cloud prompt

```text
Use case: stylized-concept
Asset type: wide landscape domain illustration for a polished dark engineering portfolio, approximately 3:2 aspect ratio.
Primary request: a bold, recognizable conceptual cloud infrastructure scene, rendered as a premium editorial 3D product illustration.
Scene/backdrop: seamless charcoal studio background and floor, base color #101719, with subtle soft contact shadows and no horizon line.
Subject: three tactile dark compute/server racks arranged in a compact isometric cluster, a sculptural translucent glass cloud hovering above, and smaller backup/storage modules linked by elegant thin cyan light paths. One restrained glass access-control gateway shape helps suggest controlled connectivity. This is a conceptual visual, not an actual deployment diagram.
Style/medium: sophisticated high-end 3D/isometric render with precise geometry, clean bevels, smoked glass, matte graphite metal, and crisp small hardware details. Product-photography quality lighting; editorial clarity; no busy sci-fi scenery.
Composition/framing: wide landscape around 3:2, centered compact composition, subjects occupy most of the frame and remain recognizable at card size, comfortable outer margins, no cropping of principal objects.
Lighting/mood: soft overhead studio light, subtle cyan/teal edge illumination, gentle reflections, cinematic but clearly readable against the background.
Color palette: charcoal and graphite, restrained cyan and teal accents, a little cool silver. Accent light is controlled, not excessive neon.
Constraints: image art only; no actual infrastructure identifiers or topology; no text, labels, numerals, UI, terminal content, charts, people, logos, brand marks, currency symbols, watermark, or screenshots. No extra decorative particle field.
```

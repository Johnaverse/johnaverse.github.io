## The challenge

An assistant connected to operational tools needs more than a useful answer. Its actions can affect the system it is helping to operate, so the workflow needs controls around what a request is allowed to become.

## My approach

I develop security guardrails for the Pinax ops-ui agent. This work sits at the boundary between AI-assisted interaction and the operational workflows behind the interface.

My security background shapes how I examine that boundary: which actions are in scope, what context the agent receives, and where the surrounding workflow should constrain its behavior. These are engineering decisions that belong alongside the agent’s capabilities.

## My contribution

I build the guardrail layer as part of my current operational tooling work. It connects my experience in blockchain infrastructure with my earlier work validating security behavior and examining attack surfaces.

## Current scope

The project is ongoing. My focus is keeping the control boundaries understandable as the agent and its operational workflows evolve.
